# 실험 실행시간과 자료 보관 지침

2026-09-12 사용자 결정. 실험 분량과 연구 판정 기준을 유지하면서 실행 효율을 높이고, 완료 자료를 원격에 보관하여 로컬 점유량을 관리한다.

1. **실험 수를 줄여 속도를 맞추지 않는다.** 등록된 방법·과제·반복·학습 경험 수·평가 상황·관측·명령·보상·종료 규칙을 유지한다. 속도 개선은 입력과 준비 계산의 재사용, 불필요한 데이터 이동 감소, 계산의 일괄 처리, CPU·GPU 자원 활용에서 찾는다.
2. **변하지 않는 입력과 준비 계산을 재사용한다.** 자료 역할, 소스, 설정, 변환 방식의 확인값으로 캐시를 구분한다. 학습·평가 자료를 섞지 않고, 현재 정책으로 새로 모아야 하는 경험을 과거 경험으로 대체하지 않는다.
3. **독립적인 작업은 함께 실행할 수 있다.** 먼저 과제별 최대 메모리, 총 처리량, 기록 일치, 저장·재개를 실제로 측정한다. 선행 결과가 필요한 작업은 의존 관계를 지킨다. 서로 다른 실험이 같은 난수 상태·출력 파일·현재 복구 파일을 공유하지 않게 한다.
4. **속도 개선과 결과 보존을 함께 검증한다.** 같은 작업량에서 손실·매개변수 갱신·보상 성분·성공/실패·움직임 지표·누락값과 실제 0의 구분을 확인한다. 비정상 수치, 안전 위반, 기록 불일치, 자원 한계에는 등록된 중단 조건을 적용하고 실패 기록을 보존한다.
5. **장치 비용과 개별 작업 비용을 구분한다.** 한 GPU에서 여러 작업을 함께 실행할 때 겹친 장치 시간과 전력을 중복 합산하지 않는다. 각 작업의 점유시간도 별도로 남긴다. 논문에서 방법별 시간·에너지를 비교할 때는 동시 실행 조건을 맞춘다. 측정하지 않은 항목은 미측정으로 기록한다.
6. **논문 작성에 필요한 표와 실험 목록은 로컬에 둔다.** 코드·환경·설정·실행 명령·학습곡선·평가 통계·전체 성공/실패·분모·누락 이유·파일 위치·확인값을 유지한다. 성공한 사례나 논문에 유리한 값만 선택해서 남기지 않는다. 큰 가중치와 상세 비행 파일은 데이터베이스의 각 행에 중복 저장하지 않는다.
7. **현재 쓰는 상태와 완료된 자료의 보관 기간을 구분한다.** 현재 학습의 최신 복구 상태와 필요한 이전 상태, 후속 학습·평가에 필요한 가중치는 로컬에 유지한다. 실험이 끝나고 후속 사용도 끝난 큰 파일은 원격 보관 대상으로 삼는다. 등록상 보존해야 하는 중간 저장본은 원격에 남기고, 폐기가 허용된 임시 자료만 해당 규약에 따라 정리한다.
8. **원격 확인이 끝난 사본만 로컬에서 비운다.** 완료 파일 목록과 크기·내용 확인값을 저장하고, 닫힌 파일만 전송한다. 변경되지 않는 원격 버전을 지정한 뒤 원격 파일 전체를 다시 읽어 원본과 비교한다. 복구도 실제로 검사한다. 전송·검증 실패 시 원본을 유지하며, 활성 파일이나 보존 대상으로 묶인 파일은 제거하지 않는다.
9. **전송은 낮은 우선순위의 별도 작업으로 진행한다.** 학습과 전송을 겹칠 수 있지만 CPU·디스크·메모리를 독점하지 않게 제한한다. 전송 속도, 학습 처리량 변화, 대기열 크기, 오프라인 동안 필요한 여유 공간을 측정한다. 재다운로드 캐시에 같은 큰 파일이 중복 상주하지 않게 한다.
10. **로컬 최대 점유량과 원격 총보존량을 따로 계획한다.** 로컬에는 논문용 기록, 현재/후속 작업의 상태, 전송 대기분, 임시 복구 공간이 필요하다. 전체 기간에 생성되는 자료를 모두 로컬에 상주시킬 필요는 없다. 기존 예산·보존 규약·자원 중단 기준의 의미를 임의로 바꾸지 않는다.
11. **공개용 자료와 비공개 복구 자료를 구분한다.** GitHub에는 공개 가능한 코드·운영 문서·작은 기록을 둔다. 미공개 가중치·복구 상태·상세 자료는 우선 비공개 원격 저장소에 보관한다. 논문 공개 시 재현과 검증에 필요한 공개 묶음을 정한다. 모든 중간 운영 파일을 무조건 공개하거나 영구적으로 로컬에 남기는 방식은 사용하지 않는다.
12. **기존 사용자 변경과 자료 역할을 보존한다.** 기존 읽기 전용 연구 결과는 자동 삭제·이동하지 않는다. 이미 노출된 확인 자료를 새 독립 평가나 학습 자료로 재사용하지 않으며, 숨김 평가·시험·분포 변화·폐기 자료를 임의로 열지 않는다. 원격에 다른 실험의 자료가 있다는 이유로 현재 연구의 입력으로 사용하지 않는다.
13. **짧은 연결 검사를 최종 연구 성과로 해석하지 않는다.** 속도·저장·재개 검사의 통과와 강화학습의 성능·우월성·일반화 검증을 구분한다. 본 학습은 해당 연구의 등록된 시작 조건을 따른다.
